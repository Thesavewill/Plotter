# Plotter

**Plotter** — Android-приложение для построения математических графиков с поддержкой распознавания формул. Пользователь может вводить функции вручную, распознавать их по фотографии или рисовать от руки, после чего приложение автоматически строит соответствующий график.

## Возможности

* 📈 Построение графиков математических функций
* ✏️ Ввод формул через встроенную математическую клавиатуру
* 📷 Распознавание формул по фотографии
* 🖍️ Распознавание рукописных формул
* 🔐 Авторизация через Google Account
* ☁️ Сохранение пользовательских графиков в облаке
* 🎨 Настройка внешнего вида графиков
* 🔍 Масштабирование и навигация по координатной плоскости
* ⚡ Поддержка пользовательских математических функций

---

## Архитектура

Приложение построено на основе архитектурного паттерна **MVI (Model–View–Intent)**, обеспечивающего однонаправленный поток данных и централизованное управление состоянием.

Проект разделён на несколько логических слоёв:

### Data Layer

Слой работы с внешними источниками данных.

* Авторизация пользователей
* Работа с облачным хранилищем графиков

### Domain Layer

Содержит бизнес-логику приложения.

* Вычисление математических выражений
* Поддержка пользовательских функций
* Распознавание формул по изображениям
* Распознавание рукописного ввода

### UI Layer

Интерфейс приложения, реализованный с использованием Jetpack Compose.

* Отрисовка координатной сетки
* Построение графиков
* Панели ввода и настройки
* Переиспользуемые UI-компоненты

### ViewModel Layer

Управление состоянием экрана и обработка пользовательских намерений в соответствии с MVI-подходом.

## Используемые технологии

### Android

* Kotlin
* Jetpack Compose
* Material Design

### Firebase

Firebase используется для:

* аутентификации пользователей;
* авторизации через Google Sign-In;
* хранения пользовательских графиков;
* аналитики приложения.

### Machine Learning

Для распознавания формул используются возможности Google ML Kit:

* распознавание текста на изображениях (OCR);
* распознавание рукописного математического ввода.

### Математический движок

Вычисление математических выражений реализовано с помощью библиотеки exp4j, которая используется для парсинга и вычисления пользовательских формул.
